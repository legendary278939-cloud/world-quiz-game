
# World Quiz Game

## About
This project was designed and developed independently by me using Python, Tkinter, and JSON.
It was built from scratch to improve my GUI programming and problem-solving skills.

## Features
- User login with nickname
- Guest mode
- Multiple-choice quiz
- 30 questions in each category
- Restart quiz
- Score tracking
- User-friendly interface

## Technologies Used
- Python
- Tkinter
- JSON

## Project Structure & Data Files
To run this project properly,ensure the following JSON data files are in the same directory as your Python script:
-'World_quiz.json' (Contains geography & general knowledge quiz questions)
-'Technology_and_innovation.json' (Contains technology quiz questions)

## What I Learned
- GUI development with Tkinter
- Event handling
- Working with JSON files
- Organizing a Python project

## How to Run
1. Clone or download this repository.
2. Ensure the JSON files are in the same folder as the Python script.
3. Run main.py.
4. Enter your nickname or continue as a guest.
5. Select a category and start playing.
